# Мой сайт

Статический сайт: index.html + app.js + style.css + data/content.json.
Работает на GitHub Pages без серверов и баз данных.

## Общий контент (виден всем посетителям)

Весь контент сайта лежит прямо в репозитории:

- `data/content.json` — приветствие, статьи, список видео и фото;
- `data/photos/…` — загруженные фотографии;
- `data/videos/…` — загруженные видео (до 95 МБ каждое; больше — только ссылкой на YouTube/VK и т.п.).

Когда администратор что-то сохраняет в панели «+ Редактирование», сайт сам делает коммит
в репозиторий через GitHub API. Все посетители получают новую версию через 1–2 минуты
(время пересборки GitHub Pages). История изменений видна во вкладке Commits.

Пока GitHub не настроен, сайт работает по-старому: контент хранится только в вашем браузере.

## Шаг 1 — загрузить сайт на GitHub

```bash
# в папке с этими файлами (index.html, app.js, style.css, README.md, data/)
git init
git add .
git commit -m "Мой сайт: первая версия"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

Репозиторий должен быть **публичным** (Public) — бесплатный GitHub Pages работает только
для публичных репозиториев.

## Шаг 2 — включить GitHub Pages

GitHub → ваш репозиторий → Settings → Pages →
Source: **Deploy from a branch** → Branch: **main** → папка **/ (root)** → Save.

Через пару минут сайт откроется по адресу:

```
https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/
```

## Шаг 3 — создать токен

GitHub (вверху справа, аватар) → **Settings** → **Developer settings** →
**Personal access tokens** → **Fine-grained tokens** → **Generate new token**:

1. Repository access: **Only select repositories** → выберите репозиторий сайта.
2. Permissions → Repository permissions → **Contents: Read and write**.
3. Generate token и сразу скопируйте его — показывается он один раз.

Токен — это ключ к вашему репозиторию: вставляйте его только на своём устройстве.

## Шаг 4 — подключить сайт к репозиторию

Откройте свой сайт, войдите как администратор → кнопка **GitHub — публикация**:

- Репозиторий: `ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ`
- Ветка: `main`
- Токен: вставьте скопированный токен
- «Сохранить настройки».

Затем один раз нажмите **«Опубликовать мой текущий контент»** — то, что вы добавляли
раньше в своём браузере (статьи, фото, видео до 95 МБ), уедет в репозиторий и станет
видно всем.

После этого каждое сохранение в «+ Редактирование» публикуется автоматически.

## Как обновить файлы сайта (код, оформление)

```bash
git add .
git commit -m "Описание изменения"
git push
```

GitHub Pages пересоберёт сайт сам.

## Заметки

- Файл `data/content.json` можно править и руками в GitHub (вкладка Code → файл →
  карандаш) — изменения появятся на сайте после пересборки.
- Если сохранение прошло, а на сайте не видно изменений — подождите 1–2 минуты
  и обновите страницу: GitHub Pages ещё пересобирается.
- Лимит GitHub: один файл до 100 МБ. Видео больше 95 МБ добавляйте ссылкой.
